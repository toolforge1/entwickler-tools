Häufig gestellte Fragen

Wie kann ich CSV in JSON umwandeln?

Fügen Sie Ihre CSV-Daten ein und klicken Sie auf „CSV in JSON umwandeln“. Das JSON-Ergebnis wird direkt angezeigt.

Werden meine Daten gespeichert?

Nein. Die Konvertierung findet lokal in Ihrem Browser statt. Die eingegebenen Daten werden nicht an unseren Server gesendet.

Kann ich das Ergebnis herunterladen?

Ja. Klicken Sie nach der Konvertierung auf „JSON herunterladen“.
