Häufig gestellte Fragen


    
Wie kann ich JSON in SQL umwandeln?

    

      Geben Sie einen Tabellennamen ein, fügen Sie Ihr JSON-Array ein
      und klicken Sie auf „JSON in SQL umwandeln“.
    


    
Welche SQL-Anweisungen werden erzeugt?

    

      Das Tool erzeugt SQL-INSERT-Anweisungen für die einzelnen
      Objekte im JSON-Array.
    


    
Werden meine JSON-Daten gespeichert?

    

      Nein. Die Konvertierung findet direkt in Ihrem Browser statt.
