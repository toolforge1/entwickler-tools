Häufig gestellte Fragen


    
Wie kann ich JSON in Text umwandeln?

    

      Fügen Sie Ihr JSON ein und klicken Sie auf
      „JSON in Text umwandeln“. Das Ergebnis wird als
      übersichtlicher Text angezeigt.
    


    
Werden verschachtelte JSON-Daten unterstützt?

    

      Ja. Verschachtelte Objekte und Arrays werden automatisch
      eingerückt dargestellt.
    


    
Werden meine JSON-Daten gespeichert?

    

      Nein. Die Konvertierung findet direkt in Ihrem Browser statt.
